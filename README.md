# MDOE (Client Utility / Prayer Mod)
Легковесный мод для **Minecraft 1.20.1 (Forge)**, добавляющий сетевое действие синхронизации/молитвы с воспроизведением колокольного звона.
---
## Возможности
- **Действие по клавише**: По умолчанию назначено на клавишу **`H`** (настраивается в разделе «Управление» → «Синхронизация»).
- **Сетевая синхронизация**: При нажатии отправляется сетевой пакет на сервер, и звук колокола воспроизводится в позиции игрока для всех окружающих.
- **Пользовательский звук**: Встроенный кастомный звук колокола (`bell.ogg`).
---
## Требования
- **Minecraft**: `1.20.1`
- **Forge**: `47.3.0` или выше
- **Java**: `17`
